# Équipe Nexus — terminal (site public)

Tableau de bord d'un système de day trading **fictif** (paper trading, aucun argent réel), actions US et européennes.
Site statique installable (PWA). Les données (`data/nexus.json`) sont publiées automatiquement par le moteur
pendant les séances (≈ toutes les 15 min). Heures de Paris.
